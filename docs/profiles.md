# Profiles

AgentReady supports these scan profiles:

- `website`: content, discoverability, policy, and safety checks
- `merchant`: product, price, checkout, refund, cancellation, support, payment, and safety checks
- `api`: OpenAPI, auth, rate limits, idempotency, payment, webhook, and safety checks
- `marketplace`: merchant and agent-service style checks for multi-party listings
- `mcp-server`: MCP metadata, OAuth discovery, API, payment, and safety checks
- `agent-service`: A2A Agent Card, task interface, payment, support, and safety checks
- `auto`: infer the most likely profile from fetched public signals
